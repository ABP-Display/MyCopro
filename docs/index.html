UN PARCOURS QUI A DU SENS

Du budget voté
au paiement vérifié.

Un appel de charges et un paiement sont deux choses distinctes. Copro. vous aide à suivre chaque étape sans les confondre.

01

Préparer l’appel

Renseignez le montant voté, la référence de décision et les échéances.

02

Vérifier les parts

Consultez la répartition lot par lot selon les tantièmes avant confirmation.

03

Enregistrer le versement

Identifiez le payeur, le compte bancaire et, si possible, l’appel concerné.

04

Valider après contrôle

Une fois le paiement vérifié, le compte est mis à jour et l’historique est conservé.

UN PROJET LIBRE

Votre hébergement.
Votre collectif.

Copro. est un projet open source, construit avec React, Django et PostgreSQL. Vous pouvez consulter son code et héberger votre propre instance avec Docker.

Consulter le code source

Démarrer une instance

  1. Récupérer le projet

    Clonez le dépôt et copiez .env.example vers .env.

  2. Renseigner votre configuration

    Choisissez vos secrets, le compte administrateur et l’adresse publique du site.

  3. Démarrer les services
    docker compose up -d --build --wait

    Ouvrez ensuite http://localhost:8081 pour configurer l’immeuble.

QUELQUES REPÈRES

Simple, et transparent.

Peut-on utiliser Copro. sans être administrateur ?

Oui. Chaque copropriétaire dispose de son accès personnel pour consulter les informations partagées et utiliser les simulateurs. Les actions de gestion sont réservées aux administrateurs.

Que signifie la validation d’un paiement ?

Un paiement enregistré peut rester à vérifier. Sa validation confirme le contrôle du versement et crée l’entrée bancaire correspondante. Copro. n’initie pas de virement et ne se connecte pas automatiquement à votre banque.

Peut-on l’installer sur téléphone ?

Oui, via la PWA sur une instance accessible en HTTPS. Le navigateur propose l’installation ou indique comment l’ajouter à l’écran d’accueil. Les données privées restent consultables avec une connexion au serveur.

Quel est le périmètre de cette version ?

Le projet se concentre sur le suivi de trésorerie, les appels, les paiements, les informations partagées et les outils de préparation. La gestion complète des assemblées générales et les annexes comptables réglementaires ne font pas partie de cette version.

Comment obtenir un accès à l’instance ?

Les accès sont créés par l’administrateur de la copropriété. Il n’y a pas d’inscription publique depuis cette vitrine. Si vous possédez déjà vos identifiants, utilisez « Accéder à Copro. ».
